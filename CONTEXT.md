# wraithcode.io

A personal site for publishing front-end experiments and writing. It is a standalone project, separate from the owner's other sites.

## Language

**wraithcode.io**:
This project — the site served at the `wraithcode.io` domain.
_Avoid_: portfolio, the site (when another project could be meant)

**Portfolio**:
A separate project owned by the same person, hosted alongside wraithcode.io today but unrelated to it. Nothing in this repo should refer to or affect it.
_Avoid_: using "portfolio" as a name for wraithcode.io
